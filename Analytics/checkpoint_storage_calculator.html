🔬 Formula

Total Checkpoint = Model_Weights × (1 + optimizer_state_multiplier) + overhead

Optimizer state multipliers:
  AdamW:       2.0x  (m + v, both full precision)
  Adam8bit:    0.5x  (m + v quantized to 8-bit → 4x smaller)
  Adafactor:   0.5x  (row/col factors instead of full tensors)
  SGD+momentum: 1.0x  (one momentum buffer)
  SGD pure:    0.0x  (no state)
  Lion:        1.0x  (one momentum buffer)
  LOMO:        0.0x  (fused, no stored state)
  GaLore:      0.1x  (low-rank projections)
  LoRA:        0.0x  (adapter weights only, ~0.1-1% of model)

Overhead = gradient buffers + FSDP metadata + RNG states (~10-20 GB typical)
