🔌 Network Blocked on EOS Compute Nodes RESOLVED

Project: Cosmos3-Nano

Error: ConnectionResetError: [Errno 104] Connection reset by peer

Cause: EOS compute nodes block outbound HTTPS. Cannot download from HuggingFace.

Fix: Download models on login nodes first, reference local /lustre/ paths from GPU jobs.

🔌 Slurm GRES Not Configured RESOLVED

Project: Nemotron-3 Nano (EOS/Ptyche)

Error: srun: error: Invalid generic resource (gres) specification

Cause: Cluster doesn't use Slurm GRES for GPU management. Partition is EXCLUSIVE = full node.

Fix: Remove --gres=gpu:8 entirely. Verified with sinfo -p batch -o "%N %G" showing (null).

Time wasted: ~30 min diagnosing why srun was rejected.

🔌 NFS Home Disk Full (Errno 28) RESOLVED

Project: Nemotron Checkpoint Conversion

Error: OSError: [Errno 28] No space left on device — couldn't create a lock file in ~/.cache/huggingface/

Cause: Megatron-Bridge's safe_config_loader.py hardcodes lock file path to ~/.cache/huggingface/, ignoring HF_HOME env var.

Fix: rm -rf ~/.cache/huggingface && ln -s /tmp/hf_cache ~/.cache/huggingface

🔌 Pyxis Mount Failure — Node-Local Path RESOLVED

Project: Nemotron Export (Ptyche)

Error: pyxis: --container-mounts: source path does not exist: /localhome/local-bbalakreshna

Cause: /localhome/ is node-local scratch. Does not exist on the newly allocated node.

Fix: Use shared NFS ($HOME) or Lustre paths for container mounts.

🔌 Checkpoint Lost on Ephemeral Storage BLOCKED

Project: Nemotron Export (Ptyche)

Cause: All srun commands used --container-mount-home only. Merged checkpoint was written to ephemeral /workspace inside a job container. When job ended, checkpoint was lost.

Lesson: ALWAYS write outputs to $HOME or Lustre. Never rely on container /workspace persistence.

⚡ Diffusers Format Not Available for Cosmos3 RESOLVED

Project: Cosmos3-Nano

Cause: Model is in Cosmos native .pt format (flat net.* keys), NOT diffusers safetensors format. No config.json.

Fix: Reverse-engineered the full architecture from 689 checkpoint keys. Built custom nn.Module matching exact tensor shapes.

Time spent: Several hours inspecting checkpoint keys and iterating on shape mismatches.

⚡ Shape Mismatches — Cosmos3 Architecture RESOLVED

Project: Cosmos3-Nano

Error: RuntimeError: size mismatch for crossattn_proj.weight: (1024, 100352) vs model (2048, 1024)

Cause: Multiple wrong dimension assumptions: crossattn_proj is a built-in vocab embedding (100352→1024), adaln uses a 256-dim bottleneck, final output is 64 not 72.

Fix: Fixed all layer dimensions by reading exact checkpoint tensor shapes. Required 5+ iterations.

⚡ Mamba/causal-conv1d CUDA ABI Mismatch BLOCKED

Project: Nemotron Export (Ptyche aarch64)

Error: undefined symbol: _ZNK3c1010TensorImpl15decref_pyobjectEv

Cause: Prebuilt mamba .so files linked against a different libtorch ABI than torch 2.10.0a0+nv25.11. The Qwen3Next model eagerly imports causal_conv1d at top-level, blocking even unrelated model exports.

Attempts: Reinstall, force source compile, purge ~/.local — all failed. Pinned versions don't link against this torch.

Recommended fix: Use nemo:25.11.nemotron_3_nano image which ships matched kernels. Purge ~/.local shadows.

⚡ DeepEP Unsupported GPU (Blackwell sm_107a) RESOLVED

Project: Nemotron-3 Nano (Hecate)

Error: ValueError: DeepEP is supported for Ampere, Hopper, and Blackwell (only B200 and B300) GPUs

Cause: Pre-release Blackwell sm_107a silicon not in DeepEP's GPU allowlist.

Fix: model.moe_token_dispatcher_type=alltoall + model.moe_flex_dispatcher_backend=none

⚡ Triton/ptxas sm_107a Not Recognized RESOLVED

Project: Nemotron-3 Nano (Hecate)

Error: ptxas fatal: Value 'sm_107a' is not defined for option 'gpu-name'

Cause: Bundled ptxas too old for pre-release Blackwell. Triton JIT compilation fails.

Fix: TORCH_COMPILE_DISABLE=1 TORCHDYNAMO_DISABLE=1 + model.bias_activation_fusion=false

⚡ PIL + fork() Segfault (Signal 11) RESOLVED

Project: Qwen2.5-VL

Error: Signal 11 (SIGSEGV) received by PID

Cause: PIL Image objects in HuggingFace Arrow datasets corrupt when accessed across forked DDP processes. C-level pointers become invalid after fork().

Fix: Decode images only in the data collator (main process). Set dataloader_num_workers=0, num_proc=1.

Time spent: This was the single most time-consuming bug — multiple hours of debugging.

🔧 HuggingFace README Invalid base_model RESOLVED

Project: Cosmos3-Nano

Error: ValueError: "base_model" with value "/lustre/fsw/..." is not valid

Cause: PEFT save_pretrained() writes local filesystem path as base_model in README.md.

Fix: re.sub(r"base_model:.*", f"base_model: nvidia/Cosmos-Predict2-2B", readme)

🔧 TypeError: unhashable type 'dict' (Double Braces) RESOLVED

Project: Nemotron-3.5

Error: TypeError: unhashable type: 'dict' on device_map={{"": 0}}

Cause: Double braces {{ }} in regular Python code creates a set containing a dict (unhashable). Only valid in f-strings.

Fix: Use device_map="auto" or device_map={"": 0}

🔧 Script Path Not Found in Container RESOLVED

Project: Nemotron-3 Nano (all Megatron runs)

Error: can't open file '/workspace/examples/...': [Errno 2] No such file or directory

Cause: Scripts live at /opt/Megatron-Bridge/ inside the container, NOT /workspace/.

Fix: find / -name "script.py" 2>/dev/null then use absolute path.

🔧 Distributed Timeout (1/2 clients joined) RESOLVED

Project: Nemotron Checkpoint Conversion

Error: DistStoreError: Timed out after 601 seconds waiting for clients. 1/2 clients joined.

Cause: Conversion is single-process but Slurm set WORLD_SIZE=2 (2-node allocation).

Fix: Use --nodes 1 or override WORLD_SIZE=1 RANK=0 LOCAL_RANK=0.

🔧 SFTTrainer API Change (max_seq_length) RESOLVED

Project: Nemotron-3.5

Error: TypeError: SFTTrainer.__init__() got unexpected keyword argument 'max_seq_length'

Cause: Newer trl moved max_seq_length into SFTConfig as max_length.

Fix: Use SFTConfig(..., max_length=1024) instead of passing to SFTTrainer.

🔧 Accelerate Unknown Key 'main_training_port' RESOLVED

Project: Qwen2.5-VL

Cause: accelerate version in container didn't support the config key.

Fix: Removed the key from YAML. Port 29500 is the default anyway.

🔧 huggingface-cli Deprecated RESOLVED

Projects: All

Fix: Use hf upload, hf auth login instead of huggingface-cli.

📊 Dataset KeyError 'context' (SQuAD processor) RESOLVED

Project: Nemotron-3 Nano (Hecate)

Error: KeyError: 'context' in process_squad_example()

Cause: Default dataset_name=json routes through SQuAD processor but actual data has input/output fields.

Fix: Monkey-patch process_squad_example to handle input/output format.

📊 KeyError 'image' vs 'images' (plural) RESOLVED

Project: Qwen2.5-VL

Cause: The Cauldron dataset uses 'images' (list of PIL) not 'image' (singular).

Fix: images = example.get("images") or example.get("image")

📊 Vision Position IDs — squeeze(0) Bug RESOLVED

Project: Qwen2.5-VL

Error: TypeError: cannot unpack non-iterable int object

Cause: .squeeze(0) collapsed image_grid_thw from (1,3) to (3,), breaking the vision encoder's position computation.

Fix: Removed .squeeze(0) from pixel_values and image_grid_thw in collator.

💾
Always Use Persistent Storage
Container /workspace is ephemeral. Write outputs to $HOME (NFS) or /lustre/. Lost an entire merged checkpoint by writing to ephemeral storage.
🔎
Inspect Checkpoints Before Coding
Run torch.load() and inspect keys/shapes first. The Cosmos3 model had a completely custom format that required reverse-engineering 689 keys.
🚫
PIL + fork() = Segfault
Never store PIL Images in Arrow datasets with multiprocessing. Decode images only in the main-process collator. Set num_workers=0.
💻
Know Your Cluster's GRES Config
Run sinfo -p batch -o "%N %G" before requesting GPUs. Some clusters don't use GRES at all (EXCLUSIVE partitions give you the whole node).
📦
Container Scripts ≠ /workspace
NeMo/Megatron scripts live at /opt/Megatron-Bridge/. Always use find / -name "script.py" to locate files inside containers.
⚡
Pre-release GPUs Break Everything
sm_107a Blackwell needed 3 workarounds: disable torch.compile, bypass DeepEP, disable bias fusion. Use matched container images.
🔗
~/.local Poisons Container Kernels
--container-mount-home shares ~/.local across ALL containers. A broken .so installed there "follows you" everywhere. Purge it.
🛠
APIs Break Frequently
trl (SFTConfig vs SFTTrainer args), huggingface-cli→hf, accelerate config keys — always check your installed version's API.
🎯
Start Single-GPU, Scale Later
Debug with CUDA_VISIBLE_DEVICES=0 first. This isolates data pipeline issues from distributed training issues.
📈
Dimension Errors Are Informative
load_state_dict size mismatch errors tell you exact checkpoint shapes. Use them to correct your model definition instead of guessing.
📋
PEFT README Fix Required for HF Upload
PEFT save_pretrained() writes local paths as base_model. HuggingFace rejects local filesystem paths. Always regex-fix before uploading.
🚀
Conversion ≠ Training (1 GPU is enough)
Checkpoint conversion is single-process. Don't allocate multi-node for it — Slurm sets WORLD_SIZE=N causing distributed timeouts.
